# Changelog

- [Added]: Initial project scaffolding with plugin.json, FancySwitcherWidget.qml, FancySwitcherPip.qml, FancySwitcherPopup.qml, and FancySwitcherSettings.qml — a DMS bar widget plugin providing workspace pips with hover-to-preview window popups, supporting Hyprland, Niri, Sway, Scroll, Miracle WM, DWL, and ext-workspace protocol (Mike Thomas, 2026-07-02)
- [Added]: README.md with installation instructions, feature overview, and architecture diagram (Mike Thomas, 2026-07-02)
- [Added]: Documentation in docs/ — overview.md, architecture.md with component diagrams, data flow, and popup lifecycle (Mike Thomas, 2026-07-02)
- [Changed]: Popup uses PanelWindow with WlrLayershell.Overlay instead of inline Rectangle, following DMS DankTooltip pattern to render above the bar surface; lazy-loaded via Loader for performance (Mike Thomas, 2026-07-02)
- [Fixed]: Removed `font.style: Font.StyleItalic` on StyledText in empty-state message — property not available in Quickshell's StyledText, causing FancySwitcherPopup type to fail loading (Mike Thomas, 2026-07-02)
- [Fixed]: Popup dismissing when hovering over window items — contentMouseArea was a sibling of the Column (behind window item MouseAreas in z-order), so containsMouse went false when mouse entered any item; moved contentMouseArea to be the outermost child with `acceptedButtons: Qt.NoButton` so it tracks hover across the entire surface without intercepting clicks (Mike Thomas, 2026-07-02)
- [Fixed]: Clicking a window only switched workspace but never focused the window — `popup.hide()` was called before `Qt.callLater` could fire the windowActivated signal, destroying the delegate context; replaced with a popup-level `_pendingFocusWindowId` property and a 50ms `focusTimer` that fires after hide, ensuring the focus dispatch survives the popup teardown (Mike Thomas, 2026-07-02)
- [Fixed]: Popup dismissing immediately when hovering window items — the popup PanelWindow was sized to its content only, which meant no Wayland input events during the gap between pip and popup; changed to a full-screen overlay with an input mask (Region) covering the popup content rect plus a connector strip to the pip, matching the AppsDockContextMenu pattern (Mike Thomas, 2026-07-02)
- [Fixed]: Window focus not working on click — increased focusTimer delay to 80ms and ensured pending window ID is stored at popup level before hide (Mike Thomas, 2026-07-02)
- [Fixed]: Hover breaking after clicking a window on the current workspace — added onVisibleChanged handler on the popup to reset hoveredWorkspaceIndex/Data when popup hides, so pip MouseAreas can re-trigger on subsequent hovers (Mike Thomas, 2026-07-02)
- [Fixed]: All monitors showing the same workspace pips (following focus) — screenName was never injected by WidgetHost for plugin widgets; changed to derive it from parentScreen.name, and removed all SettingsData.workspaceFollowFocus branches so each monitor always shows its own workspaces (Mike Thomas, 2026-07-02)
- [Fixed]: Popup hover and click completely broken by full-screen overlay approach — Region mask used an Item with no explicit size (0×0), blocking all input; replaced with a properly-sized PanelWindow whose surface spans the bounding box of pip+gap+popup so the mouse never leaves the Wayland surface; surfaceHoverArea is now the parent of all content with acceptedButtons:Qt.NoButton for hover tracking, child MouseAreas handle clicks and per-item highlights (Mike Thomas, 2026-07-02)
- [Fixed]: Clicking a window in the popup did not focus it — signal `windowActivated(string windowId)` coerced Niri's integer window IDs to strings, causing NiriService.focusWindow to send `{"id":"9"}` instead of `{"id":9}`; changed signal to `var` type and `_pendingFocusWindowId` from string to var to preserve original types (Mike Thomas, 2026-07-02)
- [Fixed]: Popup did not switch when hovering from one pip to another without leaving the widget — the PanelWindow surface needed a hide/show cycle to reposition via Wayland; added explicit `visible = false` before repositioning in `show()`, and removed the `onVisibleChanged` state reset that was clearing data during pip-to-pip transitions (Mike Thomas, 2026-07-02)
- [Fixed]: Popup still not switching between pips — the overlay surface spanned the bounding box of pip+gap+popup, covering adjacent pips on the Overlay Wayland layer and blocking their hover events; simplified surface to cover only the popup content rectangle, relying on the 400ms hide timer for gap crossing instead (Mike Thomas, 2026-07-02)
- [Fixed]: Pips vertically anchored to bottom of pill instead of centred — Flow y-position used `visualBackground.y` (top of background) instead of centering within parent; changed to `(parent.height - implicitHeight) / 2` (Mike Thomas, 2026-07-02)
- [Fixed]: Pips not scaling with bar size — widget used hardcoded `widgetHeight: 30` instead of accepting `widgetThickness` from WidgetHost; renamed property to `widgetThickness` which WidgetHost binds automatically, so pips now scale proportionally with bar thickness (Mike Thomas, 2026-07-02)
